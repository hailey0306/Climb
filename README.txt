MOE'S VALLEY PERSONAL OFFLINE GUIDE

Quick local copy: open Moes_Valley_Offline_Guide.html in a desktop browser. Data, map pins and climbing list are in this one file. Imported images are stored by your browser.

For a reliable iPhone Home Screen offline app:
1. Upload the CONTENTS of this folder to any HTTPS static hosting (e.g. GitHub Pages / Netlify).
2. Open the HTTPS URL in Safari while connected.
3. Share -> Add to Home Screen.
4. Open from Home Screen at least once online; add topo and parking screenshots.
5. Test in Airplane Mode before travel.

Note: service workers and some storage/location features do NOT work reliably when opening HTML from iOS Files. A saved HTML file is NOT equivalent to an installed PWA.

The map is a relative plot of area-level GPS points, not a satellite map or navigation trail. The 2026 temporary parking lot coordinates and construction trail lines were not verified and thus are NOT plotted. Bring the official 2026 parking map screenshot and current signage.

Route heights are unverified. No heights should be assumed to be <=10 ft. Personal photos are saved locally, not synced across devices; export your backup.
